# IR Image Viewer - 使用说明

## 📦 可执行文件信息

- **文件名**: `IR_Image_Viewer.exe`
- **位置**: `dist/IR_Image_Viewer.exe`
- **系统要求**: Windows 10/11 (64位)
- **主要功能**: 加载、显示和分析二进制格式的红外图像数据

---

## 🚀 快速开始

### 1. 运行程序

双击 `dist/IR_Image_Viewer.exe` 即可启动程序，无需安装 Python 环境。

### 2. 加载红外图像

1. 点击 **"打开文件"** 按钮 (或从文件菜单选择)
2. 选择 `.bin` 或 `.raw` 格式的红外图像文件
3. 程序会根据默认配置尝试解析图像

### 3. 配置解析参数

在側边栏或设置面板中可以调整以下参数：

- **分辨率 (Resolution)**:
  - 常用格式：640×512, 320×256, 1280×1024 等
- **像素格式 (Pixel Format)**:
  - 8-bit 或 16-bit 灰度
- **字节序 (Endianness)**:
  - 小端序 (Little Endian) 或 大端序 (Big Endian)
- **帧选择 (Frame Selection)**:
  - 如果文件包含多帧，可以使用滑块切换

### 4. 十六进制查看器

- 点击 **"Hex View"** 标签页查看原始二进制数据
- 支持搜索特定的十六进制序列
- 数据查看器与图像显示同步（点击图像位置可跳转到对应的 Hex 数据）

---

## 📊 界面说明

### 图像显示区域
- 主屏幕显示当前帧的红外图像
- 支持缩放和平移查看细节
- 鼠标悬停显示对应像素的原始数值

### 控制面板
- **文件控制**: 打开、关闭文件
- **显示设置**: 亮度、对比度调整（仅限显示）
- **播放控制**: 对于多帧文件，支持播放、暂停和跳转

### 数据分析区域
- 十六进制视图
- 像素值统计信息（最大值、最小值、平均值）

---

## 💡 使用技巧

### 1. 快速定位
在 Hex 视图中输入地址或搜索内容，快速定位到感兴趣的数据块。

### 2. 多帧分析
对于动态红外数据，利用播放控制功能观察图像变化。

### 3. 自动识别
如果文件名包含分辨率信息（如 `image_640x512.bin`），程序可能会尝试自动推断设置。

## ⚠️ 常见问题

### Q1: 图像显示为乱码或噪点？
**A**: 通常是由于分辨率、字节序或位深度设置不匹配造成的。请检查：
- 分辨率是否设置正确（宽x高）
- 16-bit 数据尝试切换小端/大端模式

### Q2: 程序无法启动或报错缺失 DLL？
**A**: 确保您的 Windows 系统已更新。如果问题持续，请尝试安装 [Microsoft Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe)。
